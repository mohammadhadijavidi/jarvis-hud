# Examples

| File | What it shows |
| --- | --- |
| `protocol-client.mjs` | Headless client that drives any backend and prints protocol events. |
| `custom-backend.mjs` | A complete backend in ~50 lines of Node, speaking the HUD protocol directly. |
| `python_backend.py` | The same idea in Python (`pip install websockets`), to show the protocol is language-agnostic. |

All examples use scripted or local logic. None of them call a model.
